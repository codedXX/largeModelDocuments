# 二叉树、红黑树、B 树与 B+ 树面试笔记设计

## 目标

为零基础、同时准备通用数据结构、Java 后端与数据库/存储引擎面试的读者，制作一篇独立可阅读的中文 Markdown 笔记。

## 读者与边界

- 默认读者不了解树、磁盘页和索引的基础概念。
- 文档聚焦二叉树、红黑树、B 树、B+ 树的结构、性质、操作特征、差异和典型应用。
- 不展开源码级实现；将红黑树旋转和 B+ 树页分裂放入进阶阅读区。

## 内容结构

1. 先给出一句话导航和树/节点/高度的必要前置知识。
2. 依次讲解四种树：直觉、结构示意图、核心约束、查找/插入特征、工程应用与面试回答要点。
3. 使用比较表从分叉数、平衡性、复杂度、数据位置、范围查询和应用场景横向对比。
4. 用“为什么数据库偏好 B+ 树”串联磁盘 I/O、索引有序性和叶子链表。
5. 结尾提供高频问答、30 秒回答模板、速记口诀和可继续深挖的主题。

## 配图

使用项目内 SVG 文件绘制四张确定性示意图：普通二叉搜索树、红黑树、B 树和 B+ 树。图中只含关键节点、指针和简短标签，避免将装饰性图像当作知识图解。正式 Markdown 通过相对路径引用，因此无需网络即可显示。

## 验收标准

- 新读者能说出四种树分别解决什么问题，以及红黑树与 B+ 树的典型使用位置。
- 面试读者能回答“为什么 HashMap 的树化使用红黑树”和“为什么 MySQL/InnoDB 使用 B+ 树”。
- Markdown 的内部链接与四张本地图片路径均有效。
- 示例中的术语、复杂度和 B/B+ 树差异保持一致。
