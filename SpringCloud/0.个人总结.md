这里的DefaultFeignConfig.class是干嘛的?



```java
package com.hmall.api.config;

import com.hmall.api.client.fallback.ItemClientFallback;
import com.hmall.common.utils.UserContext;
import feign.Logger;
import feign.RequestInterceptor;
import feign.RequestTemplate;
import org.springframework.context.annotation.Bean;

/**
 * Feign 全局默认配置类
 *
 * 作用：通过 @EnableFeignClients(defaultConfiguration = DefaultFeignConfig.class)
 *       注册后，这里定义的所有 Bean 会对【所有 Feign 客户端】统一生效，
 *       而不需要在每个 @FeignClient 中单独配置。
 *
 * 可以配置的内容包括：
 *   - Logger.Level      日志级别
 *   - RequestInterceptor 请求拦截器（例如透传用户信息、添加统一请求头）
 *   - Retryer           重试策略
 *   - ErrorDecoder      错误解码器
 *   - Contract / Encoder / Decoder 契约、编解码器等
 */
public class DefaultFeignConfig {

    /**
     * 配置 Feign 的日志级别
     *
     * Feign 日志级别共四种：
     *   NONE    : 不输出任何日志（默认值）
     *   BASIC   : 仅记录请求方法、URL、响应状态码及耗时
     *   HEADERS : BASIC 的基础上，额外记录请求和响应的头信息
     *   FULL    : HEADERS 的基础上，额外记录请求和响应的完整 body（含元数据）
     *
     * 注意：仅设置 Feign 的日志级别还不够，还需要在 application.yaml 中
     *       将对应包（如 com.hmall.api.client）的 logging.level 设为 debug，
     *       否则 Feign 日志不会被打印出来。
     *
     * @return Feign 日志级别
     */
    @Bean
    public Logger.Level feignLevel(){
        return Logger.Level.FULL;
    }

    /**
     * 配置 Feign 请求拦截器：用于透传登录用户信息
     *
     * 背景：微服务之间通过 Feign 调用时，HTTP 请求是重新发起的，
     *       网关解析出来的 userId 默认不会自动传递给下游服务。
     *
     * 解决方案：在每次 Feign 调用前，从当前线程上下文（ThreadLocal）中
     *           取出 userId，塞到 HTTP 请求头 user-info 中，
     *           下游服务再通过拦截器从 header 中取出并存入自己的上下文，
     *           从而实现用户身份在微服务链路上的透传。
     *
     * @return 请求拦截器
     */
    @Bean
    public RequestInterceptor userInfoRequestInterceptor(){
        return new RequestInterceptor() {
            @Override
            public void apply(RequestTemplate template) {
                // 从当前线程上下文中获取登录用户 id（由上游拦截器放入）
                Long userId = UserContext.getUser();
                if(userId == null) {
                    // 如果没有登录用户信息，则不做任何处理，直接放行
                    return;
                }
                // 将用户 id 放入请求头中，传递给下游微服务
                template.header("user-info", userId.toString());
            }
        };
    }

    /**
     * 注册 ItemClient 的降级处理 Bean
     *
     * 作用：当 ItemClient 调用失败或触发 Sentinel 熔断降级时，
     *       会执行 ItemClientFallback 中的逻辑返回兜底数据，
     *       避免异常向上抛出导致整个请求链路失败（服务雪崩）。
     *
     * 注意：要使降级生效，还需要：
     *   1. 在 @FeignClient 中指定 fallback / fallbackFactory
     *   2. 在 application.yaml 中开启 feign.sentinel.enabled=true
     *
     * @return ItemClient 的降级实现实例
     */
    @Bean
    public ItemClientFallback itemClickFallback(){
        return new ItemClientFallback();
    }
}

```
> **DefaultFeignConfig不需要加@Configuration注解吗？**
>
> * 简而言之：用 defaultConfiguration 显式指定的就不需要 @Configuration，加了反而可能造成 Bean 重复注册或污染全局。
